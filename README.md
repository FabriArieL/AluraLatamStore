# 🛍️ Análisis de Rentabilidad de Tiendas - Sr. Juan

## 📌 Descripción

Este proyecto tiene como objetivo analizar el rendimiento de varias tiendas bajo la administración del Sr. Juan, utilizando distintos indicadores de desempeño como ventas totales, calificaciones, rotación de productos y costos logísticos. A partir de este análisis, se busca identificar la tienda menos rentable y justificar una posible venta o cierre.

## 📊 Contenido del Análisis

El análisis incluye los siguientes elementos visuales:

- 📈 **Ventas por tienda**: comparación del volumen total de ventas entre las tiendas.
- 🥧 **Ventas por categoría** (gráfico circular): distribución de ventas según tipo de producto.
- ⭐ **Calificaciones promedio por tienda**: evaluación del nivel de satisfacción del cliente.
- 📦 **Productos más y menos vendidos**: análisis horizontal por tienda.
- 🚚 **Costo de envío promedio**: comparativa logística entre tiendas.

## ✅ Conclusiones

Tras el análisis de los datos, se determinó que la **Tienda D** es la **menos rentable**, debido a los siguientes factores:

- Tiene el **menor volumen de ventas** totales.
- Recibe **calificaciones más bajas** por parte de los compradores.
- Tiene una **alta cantidad de productos con bajas ventas**.
- Se enfoca en **categorías con poca demanda**.
- Presenta el **mayor costo promedio de envío**, lo cual reduce su rentabilidad.

> 💡 **Recomendación**: Se sugiere vender o cerrar la **Tienda D** para optimizar los recursos y mejorar la rentabilidad general del negocio.
